# 🎮 Fraudline  

Fraudline is a game project created to explore game design, storytelling, and programming concepts.  
It focuses on decision-making, strategy, and uncovering hidden truths.  

## 🚀 Features  
- Engaging storyline centered around fraud and deception  
- Player choices affect outcomes  
- Simple yet fun gameplay loop  
- Built to experiment with **Tilt Five VR**

## 🛠️ Tech Stack  
- Language: C#  
- Engine/Framework: Unity
